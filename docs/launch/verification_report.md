## 已自动覆盖的关键验收

- 角色最多三个、角色级日志/世界线隔离及级联删除。
- 状态包字段、范围、原子事务、幂等、非法包保留最后合法快照。
- 九回合序章不可跳回合，周历不可出现第 5 周，12 月可跨年。
- Weekly AP 最多透支 3 点，Event Mode 冻结日历与 AP，高阶咒语门槛失败不可改判。
- 会话鉴权、限流、CORS、输入长度、内容安全、匿名举报追踪。
- Prompt/规则/状态版本加载与编排路径。
- 年龄确认、生产配置年龄范围、隐私/AI 数据门禁。
- 首次管理员初始化是原子性的且只能成功一次；密码使用独立 salt 的 scrypt 哈希保存，已有环境变量账号可一次性迁移。
- 管理员用户名密码登录、HttpOnly 会话、登录限流与跨源写保护；游戏页保留“后台管理”入口，初始化成功后退出会返回正常登录而非再次注册。
- 供应商密钥加密落盘、列表脱敏、API 地址校验与私网访问默认拒绝。
- OpenAI Chat Completions 兼容供应商的模型发现、连接测试、原子热切换、用量聚合与审计日志。
- 通过本地独立协议服务器执行“登录 → 新建供应商 → 发现 → 测试 → 激活 → LangChain 真实调用 → 用量查询”的完整 E2E。
