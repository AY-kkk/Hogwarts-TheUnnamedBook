## 一票否决项

以下任一项未满足，结论必须是 No-Go：

- [ ] 所有 P0 任务已关闭，并关联验证证据。
- [ ] `acceptance_matrix.md` 中 P0 场景全部 Pass。
- [ ] 创建角色到 Weekly Mode 的端到端流程连续通过。
- [ ] 三角色存档、迁移、删除和恢复测试通过，无数据丢失缺陷。
- [ ] 无未修复的严重或高危安全问题。
- [ ] IP/品牌路线有书面结论，高风险素材已授权或移除。
- [ ] 隐私、AI 标识、未成年人和内容安全方案完成正式评审。
- [ ] 生产环境不包含客户端密钥、localhost API 或全开放 CORS。
- [ ] 生产监控、成本告警、值班和回滚演练通过。
