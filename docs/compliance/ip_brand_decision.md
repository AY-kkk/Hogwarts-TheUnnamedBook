## 发布路线

项目所有者必须书面确认下列路线中的一条：

### 路线 A：授权 IP 产品

进入条件：

- 提供覆盖目标发布地区、Web 产品、生成式 AI 内容、营销物料和商业模式的授权文件。
- 法务确认授权期限、地域、平台、素材范围、二次创作和模型生成内容条款。
- 建立授权素材台账以及到期、撤回和下架流程。

路线 A 完成标准：

- [ ] 授权文件引用编号已填写（不得提交合同密文）。
- [ ] 法务书面结论已归档。
- [ ] 每项高风险素材可追溯到授权或许可来源。
- [ ] 营销、产品内文案和生成式内容均在授权范围内。

### 路线 B：原创魔法世界

进入条件：

- 更换产品名、学校名、学院名、角色名、地点、校历、咒语和标志性剧情。
- 删除或重绘学院徽章、现有 IP 视觉符号及不可证明来源的素材。
- 将 Prompt 中的直接模仿特定在世/近现代作者、复刻原作事件等要求改为原创风格规范。
- 对重构后的名称、Logo、角色和世界观进行商标与版权检索。

路线 B 完成标准：

- [ ] 仓库文本扫描不再包含待移除的受控名称。
- [ ] 所有用户可见素材均有原创记录或可验证许可证。
- [ ] 新品牌和世界观通过法务复核。
- [ ] 产品说明明确这是原创作品，不暗示官方关联。
